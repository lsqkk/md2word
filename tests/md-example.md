## 一、学习前的准备：构建系统

### 1.1 目标设定：SMART原则

任何学习旅程都始于清晰的目标。一个好的目标应满足：

- **S**pecific（具体）：不要说“学英语”，而是“每天背30个单词”。
- **M**easurable（可衡量）：能通过测试或作品检验。
- **A**chievable（可达成）：挑战与能力匹配。
- **R**elevant（相关）：与长期愿景挂钩。
- **T**ime-bound（有时限）：设置截止日期。

```python
# 一个简单的目标追踪伪代码
if today.study_hours >= 2 and task_completed:
    print("✅ 今日达成目标")
else:
    print("⏰ 明日调整计划")
```

### 1.2 环境与工具

你的物理环境直接影响专注力。推荐使用：

| 要素       | 推荐配置                | 避免配置          |
| ---------- | ----------------------- | ----------------- |
| 书桌       | 整洁、只放当前学习资料   | 零食、手机、杂物  |
| 照明       | 自然光+4000K色温台灯     | 昏暗或刺眼蓝光    |
| 背景音     | 白噪音/无歌词纯音乐      | 播客、电视剧      |

## 二、学习中的执行：深度工作

### 2.1 主动回忆与间隔重复

> 被动阅读是学习的幻觉。真正有效的，是**合上书本**后强迫大脑检索信息。

具体做法：
1. 阅读一页后，尝试**用自己的话复述**关键点。
2. 使用[Anki](https://apps.ankiweb.net/)等软件进行间隔重复（Spaced Repetition）。
3. 制作**思维导图**，连接新旧知识。

### 2.2 费曼技巧——以教为学

这一技巧分为四步：
- **选择概念**：写下你想学的内容。
- **讲授给小白**：想象在教一个8岁孩子，用最通俗的语言解释。
- **发现盲点**：一旦卡住，回到原始材料。
- **简化与类比**：提炼出核心比喻。

## 三、学习后的复盘：迭代进步

- [x] 完成章节阅读

### 3.2 能量管理提醒

⚠️ **注意**：大脑不是CPU，无法持续超频。请遵守 **50/10法则**——每学习50分钟，休息10分钟（走动、喝水、眺望远处）。
